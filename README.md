# meratory5.github.io

個人で作ったアプリの紹介ページ、プライバシーポリシー、利用規約。GitHub Pages で公開している。

- https://meratory5.github.io/
- Conductor: https://meratory5.github.io/conductor/ 、`privacy.html`、`terms.html`

Google Cloud の OAuth 同意画面（ブランディング）で、ホームページ、プライバシーポリシー、利用規約のリンクと、承認済みドメイン `meratory5.github.io` に使う。

新しいアプリを作ったら、`<アプリ名>/index.html`、`privacy.html`、`terms.html` を同じ形で足し、トップの `index.html` に一覧を足す。

**秘密の情報（クライアント シークレット、トークン、パスワード）をここに置かないこと。このリポジトリは公開されている。**
