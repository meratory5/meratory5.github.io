Privacy Policy

制定・最終更新：2026年11月10日 / Effective and last updated: November 10, 2026

Conductor（以下「本アプリ」）は、開発者 meratory5 が個人で使うために作った Windows 用のアプリです。本アプリが Google アカウントのデータをどう扱うかを説明します。
Conductor ("the app") is a Windows desktop app that the developer, meratory5, made for personal use. This policy explains how the app handles data from Google accounts.

1. 読み取るデータ / Data the app accesses

ユーザーが Google のログイン画面で許可した場合だけ、次のデータを読み取り専用で取得します。
Only after the user grants access on Google's sign-in screen, the app reads the following data read-only:

  • Google カレンダー（calendar.readonly）：カレンダーの一覧と名前・色、今日から最大90日先までの予定の題名、日時、場所、通知の設定
    Google Calendar (calendar.readonly): the list of calendars with names and colors, and the title, time, location and reminder settings of events from today up to 90 days ahead
  • Google ToDo リスト（tasks.readonly）：リストの名前、未完了のタスクの題名、期日、メモ、状態
    Google Tasks (tasks.readonly): list names, and the title, due date, notes and status of open tasks

本アプリは、Google のデータを作成、変更、削除しません。
The app does not create, modify or delete any Google data.

2. 使い道 / How the data is used

読み取ったデータは、ユーザー自身の PC で次のことにだけ使います。
The data is used only on the user's own PC, and only to:

  • 本アプリの画面に予定とタスクを表示する
    show events and tasks in the app
  • 予定の前と、朝のまとめで、PC に通知を出す
    show notifications on the PC before events and in a morning summary

広告、販売、利用者の分析、機械学習の訓練には使いません。
It is not used for advertising, sale, user profiling, or training machine-learning models.

3. 保存 / Storage

  • 読み取った予定とタスクの一覧は、オフラインでも表示できるよう、ユーザーの PC（%LOCALAPPDATA%\Conductor）に保存します。
    A copy of the events and tasks is kept on the user's PC (%LOCALAPPDATA%\Conductor) so that the app works offline.
  • Google の認証情報（更新トークン）と OAuth クライアントのシークレットは、Windows のデータ保護機能（DPAPI）で暗号化して、同じ PC にだけ保存します。
    Google credentials (the refresh token) and the OAuth client secret are encrypted with Windows Data Protection (DPAPI) and stored only on the same PC.
  • 開発者のサーバーはありません。データが開発者や第三者に送られることはありません。本アプリが通信する相手は Google だけです。
    There is no developer server. No data is sent to the developer or to any third party. The app communicates only with Google.

4. 共有 / Sharing

Google のデータを、誰とも共有、販売、譲渡しません。
The app does not share, sell or transfer Google user data to anyone.

5. 削除 / Deletion

  • 本アプリの「予定」画面で「接続を解除」を押すと、PC に保存した認証情報と、取り込んだ予定・タスクの一覧を削除し、Google に許可の取り消しを依頼します。
    "Disconnect" on the app's Calendar page deletes the stored credentials and the cached events and tasks from the PC, and asks Google to revoke the access.
  • Google アカウントの設定（https://myaccount.google.com/permissions）から、いつでも許可を取り消せます。
    Access can be revoked at any time in Google Account settings at the link above.

6. Google API サービスのユーザーデータに関するポリシー / Google API Services User Data Policy

本アプリによる、Google API から受け取った情報の使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
Conductor's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. 変更 / Changes

このポリシーを変えるときは、このページを更新し、日付を改めます。
If this policy changes, this page and its date will be updated.
