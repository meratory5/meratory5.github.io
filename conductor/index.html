Conductor

Windows 用の常駐アプリです。開発者本人が、自分の PC で個人的に使うために作りました。
Conductor is a Windows desktop app. The developer made it for personal use on their own PCs.

できること / Features

  • やること（タスク）の管理と、決めた時刻の通知
    Tasks and reminders with notifications at the chosen time
  • 朝のまとめ通知（今日の予定とタスク）
    A morning summary of today's events and tasks
  • ポモドーロ・タイマー（集中と休憩）
    A pomodoro timer for focus and breaks
  • PC での定期実行（ダウンロード、バックアップなど）
    Scheduled jobs on the PC, such as downloads and backups

Google アカウントとの連携 / Google account integration

ユーザーが自分で許可した場合だけ、Google カレンダーの予定と Google ToDo リストのタスクを読み取り、Conductor の画面に表示し、予定の前に PC で通知します。Google のデータを書き換えたり、どこかへ送ったりはしません。
Only when the user grants access, Conductor reads events from Google Calendar and tasks from Google Tasks, shows them in the app, and notifies the user on the PC before events. It does not change Google data and does not send it anywhere.

許可の範囲 / Scope使い道 / Purpose
calendar.readonly今日から2週間先までの予定を、一覧と通知に使う
Show upcoming events (next two weeks) and notify before them
tasks.readonly未完了のタスクを、一覧と朝のまとめに使う
Show open tasks in the list and in the morning summary

読み取ったデータと認証情報は、ユーザーの PC の中だけに保存します。開発者のサーバーはありません。詳しくはプライバシーポリシーをご覧ください。
Data and credentials stay on the user's PC only. There is no developer server. See the Privacy Policy.
